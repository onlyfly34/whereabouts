# 世界的下落 · WHEREABOUTS

> 有些事沒有結局，只是沒有人再問起。

🔗 **https://whereabouts.skya.tw**

一個記錄「還沒有結局、卻漸漸被遺忘的世界大事」的互動網頁。

推開一扇門，走進深夜的檔案房。地上散落著一份份卷宗——空難的調查報告、停不下來的戰爭、沒等到的究責。每份卷宗貼著一張便條紙，寫著它被擱置了幾天。撿起一份、撕下便條、翻開，讀完，再輕輕放回地上。

*Some things never got an ending — people just stopped asking. An interactive web experience: step into a dim archive room at night, pick up a dusty case file from the floor, and read the story of a world event still waiting for its ending.*

## 檔案

- `index.html` — 互動場景（Babylon.js，單檔，無建置步驟）
- `events.yaml` — 所有事件內容（繁體中文 / English 雙語），**本站唯一的資料來源**

本機預覽：在這個資料夾起一個靜態伺服器即可，例如 `python3 -m http.server`。

## 貢獻內容

歡迎發 Pull Request 補充進展、新增資料來源、或提議新事件——**只需要編輯 `events.yaml` 一個檔案**，不用懂程式。檔案開頭的註解就是完整的欄位說明與操作指南。

- 補一筆進展：在該事件 `timeline` 加一個節點（日期＋一句話＋來源），並更新 `last_progress`
- 補資料來源：替缺少 `source` 的節點補上可信來源的連結
- 事件結案：`status` 改為 `closed`，加上 `outcome`
- 新增事件：複製一段既有事件修改；需符合下方收錄標準
- 每個文字欄位都要有 `zh`（繁體中文）與 `en`（英文）兩個版本；只會寫其中一種語言也可以先發 PR，缺的另一半由維護者補

文字原則：每個節點一句話，精簡克制、不狗血；究責與事實，不要情緒。

## 收錄標準（草案）

什麼樣的事件能成為這個房間裡的一份卷宗？為了避免卷宗無限增加，目前的門檻草案如下（仍在演進，維護者保留最終裁量）：

1. **公共性與規模** — 影響範圍達國家級以上，或直接衝擊大量人群：大規模傷亡或失蹤、數十萬人以上流離失所、全國性的制度或公衛衝擊。私人糾紛與名人新聞不收。
2. **懸而未決** — 必須存在一個說得出口的「還沒有答案的問題」：調查未定案、戰爭未停火、責任未釐清、人未尋獲。沒有未解問題的事件不立案。
3. **被遺忘中** — 已退出每日新聞熱度（原則上距事件起點至少 3 個月）。這個房間收的是「大家不再問起」的事，不追熱點。
4. **可查證** — 至少 2 個獨立可信的公開來源（官方報告、國際通訊社、具公信力媒體），時間軸的關鍵節點都要能對應來源。陰謀論與未經證實的指控不收。
5. **可敘事** — 能整理成「立案日 → 幾個關鍵節點 → 目前卡在哪」的一條時間軸，每個節點一句話講得清楚。
6. **究責或真相導向** — 純粹的自然災害本身不收；但其後續的調查、究責、重建若懸而未決，可收。

規模控制：同時未結案（`open`）的卷宗以 **20 件**為上限原則。滿了之後，新事件要進來，就先檢視是否有舊事件該結案歸檔，或已不再符合標準。
